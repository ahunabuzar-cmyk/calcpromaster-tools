Loan EMI

EMI = P x r x (1 + r)^n / ((1 + r)^n - 1)

A 500,000 loan at 8 percent over 20 years works out to about 4,182 per month. Worked example: EMI calculator guide.

Percentage change

Change = (new - old) / old x 100. See percentage tools.

BMI

BMI = weight in kilograms / height in metres squared. See BMI calculator.
